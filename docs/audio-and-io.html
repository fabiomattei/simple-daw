Audio, MIDI & Files

Sample playback, recording and importing audio, MIDI import, and getting a song in and out of the app.

Sample playback

Any Step Grid lane can be backed by a loaded WAV sample instead of a synth, via the sample-load controls on that lane's row in the Beats window. Samples play through a per-track 32-voice one-shot pool, resampled to the output device's sample rate at load time. A loaded sample always takes priority over a synth on that lane.

Audio tracks

An Audio track holds recorded or imported WAV clips positioned on the Playlist timeline, the audio equivalent of a Step Grid/Piano Roll track's Regions.

  • A newly-created Audio track is armed for recording automatically; use the Input device picker on its Channel Rack row to choose a source (or leave it on Default). The Trim slider next to it sets input gain going into the recording — separate from the track's Volume fader, which only affects playback.
  • The toolbar's ⏺ Record button starts/stops recording live input straight to a WAV file, dropped onto the armed track's timeline as a clip. A level meter shows input (after Trim is applied) while recording.
  • To bring in an existing WAV file instead, import it the same way onto an Audio track.

MIDI import

Use File → Import MIDI… to load a standard .mid file into a track's Piano Roll. There's an option to also apply the file's detected tempo to the song's BPM.

Saving and loading songs

The whole song — tracks, Regions, sample paths, loaded effect paths and their parameter values — round-trips through the File menu as a JSON file:

  • Load… — open a song file.
  • Save — save to the currently-open path.
  • Save As… — save to a new path.

Old save files predating the Region-based model still load, migrated automatically.

WAV export

File → Export… opens the export dialog: set an output path and a loop count (how many times the arrangement repeats in the bounced file), then click Export.

Export reuses the exact same sequencing/mixing code as live playback, but it's dry only — CLAP and built-in effects, sends, and automation aren't included in the bounce, only each track's Volume/Pan and the raw synth/sample/step sequencing (see Effects).

Transport & output device

The top toolbar has the main transport (▶/⏹ play/stop, ⏺ record, 🔔 metronome toggle) and, on the right, pickers for the output audio device and its sample rate — switching either restarts the audio engine.
