Data Model

src/model.rs is the pure data model — no audio, no UI. It owns JSON save/load (serde) and migration of older song-file shapes. Everything on this page is plain data; how it's turned into sound lives in Engine Architecture.

Shape at a glance

Song
├─ tracks: Vec<Track>
│   ├─ kind: TrackKind            (StepGrid | PianoRoll | Audio)
│   ├─ regions: Vec<Region>       (StepGrid/PianoRoll tracks)
│   │   └─ content: RegionContent (StepGrid(Vec<Lane>) | PianoRoll(Vec<Note>))
│   ├─ audio_clips: Vec<AudioClip>   (Audio tracks)
│   ├─ take_folders: Vec<TakeFolder> (Audio tracks, recorded only)
│   │   └─ takes: Vec<Take>, comp: Vec<CompSegment>
│   ├─ effects: Vec<TrackEffectConfig>
│   ├─ send_levels: Vec<f32>       (index-aligned with Song.sends)
│   ├─ output: TrackOutput          (Master | Submix(index))
│   └─ automation: Vec<AutomationLane> (track-wide, absolute-tick)
├─ tempo_map: Vec<TempoPoint>
├─ master_effects: Vec<TrackEffectConfig>
├─ sends: Vec<SendBus>
├─ submixes: Vec<SubmixBus>
├─ plugins: Vec<ProjectPlugin>      (known CLAP plugin paths)
└─ synth_presets: Vec<SynthPreset>  (song-local presets)

Song

FieldTypeMeaning
nameStringSong title.
bpmf32Tempo at the start of the timeline. Still the single source of truth for every one-shot tempo read/write (transport LCD, MCP set_bpm, tap tempo, MIDI import).
tempo_mapVec<TempoPoint>Subsequent tempo-change points, purely additive. Song::bpm_at(tick) resolves the tempo in effect at any tick.
tracksVec<Track>Every track, in display/mix order.
next_note_idu64Monotonic id counter for piano-roll Notes across the whole song.
master_effectsVec<TrackEffectConfig>The master bus's own effect chain, processed after every track/submix is mixed.
pluginsVec<ProjectPlugin>Known CLAP plugin paths for this project (feeds the plugin-picker UI).
synth_presetsVec<SynthPreset>Custom presets saved with this song (distinct from the built-in factory catalog in src/factory_presets.rs).
time_signature_numerator / _denominatoru8Song time signature.
sendsVec<SendBus>Aux send buses. Index-aligned with every track's own send_levels.
submixesVec<SubmixBus>Alternate-output group buses a track can route to instead of master.

Track

nameString

Region & RegionContent

A Region is a track's own musical content, positioned independently on that track's Playlist row (Logic/Ableton-style) — unlike a shared FL-Studio-style Pattern, placing similar material twice always means two independent copies.

FieldTypeMeaning
nameString 
start_tickusizeAbsolute song position.
content_length_stepsusizeThe content's own natural length, auto-grown to fit the furthest Piano Roll note by grow_length_to_fit_notes. Never shrinks.
loop_length_stepsusizeThe on-timeline span this region occupies. Shorter than content_length_steps truncates; longer loops. Dragging a region's right edge in the Playlist controls this only.
contentRegionContentStepGrid(Vec<Lane>) or PianoRoll(Vec<Note>).
fade_in_ticks / fade_out_ticksusizeLinear ramp to/from silence at the region's on-timeline edges — see fade_gain_at, applied per-tick since it must scale already-triggered, freely-ringing voices.
automationVec<AutomationLane>Region-local-tick lanes, only in effect while this region is the active one on its track.

Lane & StepData (step-grid content)

FieldTypeMeaning
Lane.nameString 
Lane.pitchu8MIDI pitch used when the lane is driven by a synth.
Lane.stepsVec<Option<StepData>>One slot per grid step; None is an inactive step.
Lane.sample / sample_pathOption<Arc<SampleBuffer>> / StringAn optional one-shot sample that, if loaded, takes priority over any synth on this lane.
Lane.synth_override / synth_engine / synth / trine / wave Per-lane synth patch overriding the track's own, when synth_override is set.
StepData.velocityu8Defaults to 100 on a newly-toggled step.
StepData.timing_offset_ticksi8Nudge from this step's own grid position, clamped to ±MAX_STEP_TIMING_OFFSET_TICKS (11 ticks, half a step minus one — never crosses into a neighboring step). StepData deserializes from either its own object shape or a bare legacy velocity byte, so old song files still load.

Note (piano-roll content)

FieldTypeMeaning
idu64Stable identity for selection/editing, assigned from Song.next_note_id.
pitchu8MIDI pitch.
start_tick / length_ticksusizeRegion-local position/duration. Notes trigger by exact-tick equality on start_tick.
velocityu80..127.

TICKS_PER_STEP = 24 throughout the model — all tick-based fields on this page share that resolution.

AudioClip

Has no stored length by default — playback runs until the decoded buffer is exhausted — but can be trimmed non-destructively and carries the Flex Time/Pitch edit results.

FieldTypeMeaning
start_tickusizeAbsolute song position.
file_pathStringSource WAV path.
gainf32Linear playback gain, 1.0 unity.
source_start_frameusizeHead trim — real sample frames into the decoded (already warped/pitch-corrected) buffer.
length_ticksusizeTail trim, on-timeline duration. 0 is a sentinel meaning "play to the end of the buffer" — see effective_length_ticks/full_length_ticks.
fade_in_ticks / fade_out_ticksusizeThe AudioClip counterpart of Region's fades — but ramped per-sample inside SampleVoice, not per-tick.
pitch_correctionsVec<PitchCorrection>Flex Pitch: retargeted ranges, applied by load() before warp_markers so a correction always indexes the unwarped recording.
warp_markersVec<WarpMarker>Flex Time: a piecewise source-to-output time map. Fewer than 2 markers means untouched.
buffer / load_error#[serde(skip)]Decoded audio and any load failure — not persisted, rebuilt by load() after deserialization.

WarpMarker & PitchCorrection

TypeFieldsMeaning
WarpMarkersource_frame: usize, output_frame: usizeOne point in the Flex Time map: where a transient is in the recording → where it should land on the timeline. stretch::warp_buffer WSOLA-stretches each span between consecutive markers.
PitchCorrectionstart_frame: usize, end_frame: usize, target_semitones: f32One retargeted Flex Pitch note. Stored independently of pitch::detect_notes' own output, so a saved correction survives even if detector constants change later.

Take Folders & comping

TypeFieldsMeaning
TakeFolderstart_tick, length_ticks, gain, takes: Vec<Take>, comp: Vec<CompSegment>Every take shares the folder's own start_tick/length_ticks — a take has none of its own.
Takefile_path, buffer, load_errorJust a recorded pass; no position/gain/trim of its own.
CompSegmentstart_tick: usize, end_tick: usize, take_index: usizePiecewise, always-gapless map of which take is heard for a stretch of the folder's span (relative to the folder). The sorted/gapless/non-overlapping invariant is maintained by every mutator (add_take_and_activate, assign_take_to_range).

Automation

TypeFieldsMeaning
AutomationLanetarget: AutomationTarget, points: Vec<AutomationPoint>One automated parameter's "ride." Lives on a Region (region-local ticks) or a Track (absolute song ticks).
AutomationPointtick: usize, value: f32Linearly interpolated between neighbors by value_at_fractional; holds the nearest point's value outside the lane's own range.
EffectParamKeyClap {'{'} param_id: u32 {'}'} or BuiltIn {'{'} param_name: String {'}'}Addresses one parameter within an effect slot — CLAP plugins by stable numeric id, built-ins by field name.

AutomationTarget variants — a lane always lives on one region/track, but its target doesn't have to be that same owner:

VariantRides
Volume / PanThis lane's own track's fader/pan.
SendLevel {'{'} send_index {'}'}This track's own send_levels[send_index].
EffectParam {'{'} slot_index, key {'}'}A parameter in this track's own effects[slot_index].
OtherTrackVolume / OtherTrackPan {'{'} track_index {'}'}A different track's fader/pan.
OtherTrackSendLevel {'{'} track_index, send_index {'}'}A different track's send level.
OtherTrackEffectParam {'{'} track_index, slot_index, key {'}'}A parameter in a different track's own chain.
SendEffectParam {'{'} send_index, slot_index, key {'}'}A parameter in a send bus's own chain.
MasterEffectParam {'{'} slot_index, key {'}'}A parameter in the master bus's own chain.
There is no SubmixEffectParam variant — a submix's chain/volume aren't automatable.

TrackEffectConfig

One entry in any effect chain (track/master/send/submix) — #[serde(tag = "kind")] so a saved song's JSON is self-describing about which effect each slot holds.

VariantKey fields
Clappath, params: Vec<(u32, f64)> (by CLAP param id, not index), sidechain_source: Option<usize>
Delaytime_ms, feedback, mix
Bitcrusherbit_depth (1..16), rate_divisor, mix
Distortiondrive, mix
Reverbroom_size, damping, mix
Chorusrate_hz, depth_ms, mix
Filtercutoff_hz, resonance, mode: FilterMode, mix
Tremolorate_hz, depth
Compressorthreshold_db, ratio, attack_ms, release_ms, makeup_db, sidechain_source
Flangerrate_hz, depth_ms, feedback, mix
Phaserrate_hz, depth, feedback, mix
RingModulatorcarrier_hz, mix
NoiseGatethreshold_db, attack_ms, release_ms, range_db, sidechain_source
PhaseInvertinvert_left, invert_right (no dry/wet mix — it's a phase toggle, not tone shaping)
ChannelEqbands: Vec<EqBand> — fixed 8-band chain (low cut, low shelf, 4 peaking, high shelf, high cut), each with band_type/freq_hz/gain_db/q/enabled
Limiterinput_gain_db, ceiling_db, release_ms — look-ahead, so a hard ceiling rather than Compressor's soft target

sidechain_source: Option<usize> (on Clap, Compressor, NoiseGate) is an index into Song.tracks of a track whose pre-effects signal feeds this slot's sidechain key input instead of its own — silently ignored if the loaded plugin/effect doesn't actually support a second input.

Buses

TypeFieldsMeaning
SendBusname, effects: Vec<TrackEffectConfig>An aux bus. No fader/pan of its own — a track's own send_levels[i] is the only level control.
SubmixBusname, effects, volume, pan, muted, soloAn alternate-output group bus (Track Stack equivalent). Has its own volume/mute/solo (it stands in for its members' direct mix contribution) but per-track panning still applies upstream.
TrackOutputMaster \| Submix(usize)Where a track's Track::output points. Removing a submix resets any track pointed at it back to Master and shifts down indices of tracks pointed past it.

Synth engine params (overview)

Each track always allocates all three engines' param structs; synth_engine picks which one is live. Full field-by-field docs live as doc comments directly on each struct in model.rs — this is a map of what's there, not an exhaustive list.

TypeShape
SynthParams (Simple)Waveform, pulse width, unison (voices/detune/width), ADSR, filter (cutoff/resonance/env amount/type), sub-oscillator mix, one LFO (waveform/rate/target/depth), glide.
TrineParamsThree oscillators, FM amount, ring-mod mix, analog drift (per-channel, drives its dual-mono stereo width), dual filter (FilterRouting, drive, FM amount, FilterSlope), a mod matrix (mod_slots: Vec<ModSlot>, each a ModSource → ModTarget pair with an amount).
WaveParams (Wave)Two wavetable oscillators with position-morph and phase-warp, unison, sub-oscillator (level/semitones), noise level, the same dual filter/mod-matrix machinery as Trine (mod_slots: Vec<WaveModSlot>), amp ADSR.
