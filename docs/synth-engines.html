Synth Engines

Every track picks one of three independently-parameterized synth engines. They're parallel options, not layers stacked on top of each other.

EngineCharacter
Simple The original engine: a sine-family oscillator with an exponential-decay envelope. Percussive only — good for kicks, claps, simple blips.
Trine Multi-oscillator, with a filter and modulation matrix (mod sources routed to mod targets via configurable slots). The most flexible general-purpose engine.
Wave Two wavetable oscillators with position-morphing and phase-warp, built on the same dual-filter/mod-matrix machinery as Trine.

Pick a track's engine from its editor panel; each engine has its own parameter layout tailored to how it synthesizes sound.

Presets

Each track's synth editor has a Preset picker, split into two groups:

  • Factory — the built-in preset library shipped with the app (several patches per engine: leads, pads, basses, plucks, FX). Not saved into your song file — they're always available.
  • Custom — presets you've saved or imported into the current song. These are saved with the song.

Selecting a preset from either group loads its parameters into the track's current engine. Use Import… to load a preset from a standalone JSON file.

Per-lane synth override

Inside a Step Grid track's Beats window, each lane has a 🎹 button. Enabling it gives that one lane its own synth engine and patch, completely independent of the track's synth — so a single step-grid track can, for example, play a kick patch on one lane and a hi-hat patch on another. A lane's loaded sample (if any) still takes priority over both its own synth and the track's.
