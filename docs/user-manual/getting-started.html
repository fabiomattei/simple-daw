1. Getting Started

From a clean checkout to your first audible sound.

Install

  • A Rust toolchain, installed via rustup.
  • On Linux: ALSA development headers for cpal's audio backend (alsa-lib-devel on Fedora, libasound2-dev on Debian/Ubuntu).
  • Optional: a .clap plugin on disk if you want to try CLAP effect hosting — none ship with the repo (see Mixing & Effects).

Build & launch

cargo build       # debug build
cargo run         # launch the GUI app

The app opens with a small demo song already loaded — a programmed "Drums" step-grid track with a basic beat — and a docked Channel Rack panel on the left. Press ▶ in the top toolbar to hear it immediately. There's no File → New; you either keep building on what's loaded or use File → Load… to open a different song (see Files, MIDI & Export).

A tour of the main window

  • Top toolbar — transport (play/stop, record, metronome), tempo (BPM field, TAP button), and the output audio device/sample-rate pickers on the right.
  • Channel Rack (left, dockable or its own window) — where tracks are created and their mute/solo/FX controls live.
  • Playlist (center) — the song-wide arrangement timeline; every track's Regions or audio clips are placed here.
  • Mixer — channel strips, sends, submixes, and metering, opened from its own window/tab.
  • Beats and Piano Roll windows open when you double-click a Region on the Playlist, matching that Region's track kind.

Adding your own track: a synth bassline

  1. In the Channel Rack, click + Add and choose Piano Roll Track. It appears in the rack, alongside the demo song's Drums track, and gets its own empty row on the Playlist.
  2. On the Playlist, click empty space on that new track's row to create a one-bar Region.
  3. Double-click the Region to open the Piano Roll. Click a few cells in the grid to drop notes — pitch on the vertical axis, time on the horizontal.
  4. Press ▶ in the top toolbar. You should hear your notes playing alongside the demo drum beat.

From here, Tracks & Playlist covers every editing gesture on the Channel Rack/Playlist/Beats/Piano Roll in full, and Synth Engines covers shaping that kick's own sound (or picking a completely different one from a preset).

Saving your work

File → Save As… writes the whole song — tracks, Regions, sample paths, loaded effect paths and their parameters — to a JSON file. File → Save re-saves to that same path afterward. See Files, MIDI & Export for loading songs back and bouncing to WAV.
