4. Editing Audio

Non-destructive editing for recorded/imported clips on Audio tracks: trim, fades, comping between multiple takes, silence removal, and time/pitch editing.

All of this applies to Audio tracks (see Tracks & Playlist for creating one and recording or importing a clip onto it).

Trim and fades

A clip has no fixed length until you trim it — by default it plays the whole underlying file. On the Playlist, drag a clip's edges/corners to edit it non-destructively (the source file itself is never modified):

DragEffect
Left edgeTrim the start (head trim) — moves the clip's on-timeline start, keeping its end fixed.
Right edgeTrim the end (tail trim) — shortens or extends how much of the clip plays before it stops.
Top-left corner handleFade-in, shown as a shaded triangle.
Top-right corner handleFade-out, shown as a shaded triangle.

Unlike a Region's fade (which ramps per-tick), an audio clip's fade ramps per-sample, so it stays smooth regardless of tempo.

Take Folders and comping

Recording is grouped for comping automatically — importing or dragging in a file is not. Re-record from the exact same start position on the same track and the new pass joins the existing recording as another take in a Take Folder, instantly comped in for the whole span. Recording from anywhere else starts a fresh folder.

  • Right-click a Take Folder on the Playlist for a whole-take picker (swap which take plays for the entire folder) plus delete.
  • Double-click a Take Folder to open the comp-editor window: one waveform lane per take, stacked. Drag horizontally across a lane to "paint" that stretch of time onto that take — the comp stays gapless automatically as you paint across lane boundaries.
  • Every switch between takes gets a fixed 5ms auto-crossfade, so a take-switch mid-folder never clicks.

Transient detection and Strip Silence

A clip's waveform shows yellow tick marks at detected transients (attacks), recomputed live as you view it. Right-click a clip and choose Strip Silence to replace it with one new clip per non-silent segment (a fixed-threshold gate with hysteresis, so a brief dip mid-word doesn't fracture a take) — each new clip stays anchored to the exact same absolute song position its audio originally occupied, so anything synced against it doesn't drift; each starts with fresh trim and no inherited fades.

Flex Time and Flex Pitch

Right-click a clip and choose Flex Time / Pitch… to open the flex editor, with two tabs. Both tabs preview live as you drag and only commit (re-processing the audio) when you release the mouse — dragging itself doesn't re-run the DSP on every frame.

TabWhat it does
TimeDrag a warp point (snapped to a detected transient) to stretch the audio around it, changing duration without changing pitch — built on WSOLA (Waveform Similarity Overlap-Add), which keeps consecutive grains in phase so stretched audio doesn't "warble."
PitchDrag a detected note vertically to retarget its pitch, centered on a "no change" gridline — changes pitch without changing the note's duration.
Both are hand-rolled time-domain DSP, functionally verified (hits its target duration/ frequency, silence stays silent) but not verified by ear — extreme stretch/shift amounts can still produce audible artifacts a listening pass would catch.

Edits are baked into the clip's own decoded audio once, at load time — everything else (trim, fades, WAV export) treats a flexed clip exactly like an ordinary one.
