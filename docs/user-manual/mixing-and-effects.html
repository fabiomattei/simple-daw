6. Mixing & Effects

Channel strips, buses, built-in DSP, CLAP plugins, sidechaining, freezing, and automation — everything that shapes a track's signal on its way to the speakers.

The Mixer

Every track gets a channel strip: volume fader, pan, mute/solo, an FX chain, and a Sends menu. Each strip shows a live peak/RMS bar meter plus LUFS loudness (momentary/short-term always for master; hover a track's integrated reading for the same breakdown). Integrated LUFS resets on every transport stop, so it reads "since the last time playback started," the way a loudness-meter plugin is normally used.

Per-track FX chain

Open a track's FX menu from its Channel Rack row. Effects added there run in order, on that track's signal only. Each slot shows a Params button (to edit the effect), any load/status message, and a remove button.

Master bus FX

The master bus has its own effect chain, applied after every track (and every submix — see below) has been mixed together, configured the same way as a per-track chain — open it from the Plugins window's "Master bus FX chain" section.

New songs start with a built-in Limiter already loaded on the master bus (a look-ahead peak/brickwall limiter, not a same-instant compressor — see its params for ceiling/release/input gain), the same way Logic ships an Adaptive Limiter on the master by default. Remove it from the chain if you don't want it.

Send buses

The Mixer's + Add Send button creates a named aux bus with its own FX chain (built-in and/or CLAP, configured exactly like a track's or the master's). Each track gets a Sends menu on its Mixer channel strip with one level knob per send bus — raising it feeds that much of the track's post-fader/pan signal into the send, in parallel with its normal path to the master bus. A send bus has no fader or pan of its own in this minimal model: its own chain and each track's level knob are the only controls.

Sends are a live-mixing feature only — like the rest of the effect chains, they're excluded from WAV export (see Files, MIDI & Export).

Submix buses (Track Stacks)

A track can route its output somewhere other than the master bus: pick a submix from the Output dropdown on its channel strip instead of the default "Master." This is this app's version of Logic's Track Stack (one shared fader and one shared insert chain over a group of tracks) — there's no separate "group" concept, a submix bus is the group.

  • Create one from the Mixer's + Add Submix button, name it, then point every track that belongs to the group at it via its Output dropdown.
  • A submix has its own volume and mute/solo, and its own FX chain — but no pan (panning stays per-track) and no automation of its own.
  • Soloing or muting a submix acts like soloing/muting every member track at once — the same "solo wins" rule a plain track solo already applies.
  • Removing a submix sends every track that was routed to it back to Master.

Sidechain routing

The Compressor and Noise Gate built-in effects, and any CLAP plugin that declares a second audio input, can duck/gate against a different track's signal instead of their own. Open the effect's Params and pick a Sidechain source track — its pre-effects signal now drives the envelope follower instead of the host track's own. Leave it on "None" for ordinary (non-sidechained) behavior.

A CLAP plugin's sidechain input only activates if that specific plugin actually declared a second input port — picking a source on a plugin that doesn't support it is silently ignored, the same tolerance an automation lane pointed at a deleted track already has.

Freeze / bounce-in-place

Right-click a track's row in the Channel Rack and choose Freeze to render its current output (synth/sample playback plus its own FX chain) down to a single audio clip, then play that clip back instead of re-synthesizing live — useful to save CPU on a CPU-heavy synth patch or a long CLAP effect chain. The track's own FX chain is bypassed while frozen (its output is already baked into the frozen clip). Unfreeze restores live synthesis and re-enables the chain.

Plugin delay compensation

Some effects (particularly look-ahead ones like the built-in Limiter, and some CLAP plugins) introduce a small amount of processing latency. The mixer automatically delays every other track by the right amount so a track running a latent effect still lines up in time with the rest of the mix — nothing to configure, this happens transparently during playback.

CLAP plugin hosting

Any FX slot (per-track, send, submix, or master) can instead host a CLAP plugin:

  • + Add Effect → CLAP Plugin… creates an empty slot, then either browse for a .clap file on disk or pick one from the project's plugin library.
  • Once loaded, its Params button opens either the plugin's own GUI (embedded in the window when the plugin and platform support it, otherwise a floating window it owns) or, if it declines both, a generic parameter window built from its own declared CLAP parameters.
CLAP hosting has no unloading a plugin once it's loaded mid-session, and no automation recording from moving a knob live. An embedded plugin GUI's panel is sized once, at open time — it doesn't renegotiate live if the plugin later asks to resize.

Loaded plugin paths and their parameter values are saved with the song (see Files, MIDI & Export) and restored on load.

WAV export (bounce) mixes every track/submix/send's effect chain and automation into the file — the only thing it doesn't consult is mute/solo, which the offline bounce ignores entirely (every track always renders). See Files, MIDI & Export.

Automation ("rides")

Two places to add automation lanes, both edited the same way (click empty space on the lane's graph to add a point, drag a point to move it, right-click to delete it — a straight line between two points is a ramp, more points make a full "ride"):

  • Region automation — an "Automation" panel below the Piano Roll/Beats grid for whichever Region is currently open (see Tracks & Playlist). Points are positioned relative to the Region's own start, and the lane is only in effect while that Region is the active one on its track.
  • Track automation — a separate "Track Automation" panel, always shown for whichever track is selected, for lanes that apply across the whole arrangement (absolute song ticks), including stretches where the track has no active Region at all. Where a track-wide lane and an active Region's lane target the same parameter at the same tick, the Region's own lane wins.

A lane's + Add Lane menu can target more than just the track it lives on:

  • This track's own Volume, Pan, or a send level.
  • A parameter of an effect in this track's own FX chain (built-in effects expose their sliders by name; a CLAP plugin's parameters are only offered once it's actually loaded into that slot).
  • Other Track — a different track's Volume, Pan, send level, or effect parameter.
  • Send FX — a parameter of an effect loaded in a send bus's own chain.
  • Master FX — a parameter of an effect loaded on the master bus.
There's no automation target for a submix bus's own chain or volume — those stay static.
