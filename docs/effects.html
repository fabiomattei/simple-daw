Effects

Effects can be inserted per track and on the master bus, mixing built-in DSP with hosted CLAP plugins.

Metering

Every track's Mixer channel strip (and the master strip) shows a live peak/RMS bar meter plus LUFS loudness (momentary/short-term always for master; hover a track's integrated reading for the same breakdown). Integrated LUFS resets on every transport stop, so it reads "since the last time playback started," the way a loudness-meter plugin is normally used.

Per-track FX chain

Open a track's FX menu from its Channel Rack row. Effects added there run in order, on that track's signal only. Each slot shows a Params button (to edit the effect), any load/status message, and a remove button.

Master bus FX

The master bus has its own effect chain, applied after every track has been mixed together, configured the same way as a per-track chain — open it from the Plugins window's "Master bus FX chain" section.

New songs start with a built-in Limiter already loaded on the master bus (a look-ahead peak/brickwall limiter, not a same-instant compressor — see its params for ceiling/release/input gain), the same way Logic ships an Adaptive Limiter on the master by default. Remove it from the chain if you don't want it.

Send buses

The Mixer's + Add Send button creates a named aux bus with its own FX chain (built-in and/or CLAP, configured exactly like a track's or the master's). Each track gets a Sends menu on its Mixer channel strip with one level knob per send bus — raising it feeds that much of the track's post-fader signal into the send, in parallel with its normal path to the master bus. A send bus has no fader or pan of its own in this minimal model: its own chain and each track's level knob are the only controls.

Sends are a live-mixing feature only — like the rest of the effect chains, they're excluded from WAV export (see below).

CLAP plugin hosting

Any FX slot (per-track or master) can instead host a CLAP plugin:

  • + Add Effect → CLAP Plugin… creates an empty slot, then either browse for a .clap file on disk or pick one from the project's plugin library.
  • Once loaded, its Params button opens a generic parameter window built from the plugin's own declared CLAP parameters.
CLAP hosting is intentionally minimal: there's no plugin-native GUI (only the generic host-side Params window), and no unloading a plugin once it's loaded mid-session. A loaded plugin's parameters can be automated per-Region (see below), but there's still no generic per-parameter automation lane list independent of a Region, and no automation recording from moving a knob live.

Loaded plugin paths and their parameter values are saved with the song (see Audio, MIDI & Files) and restored on load.

WAV export (bounce) is dry-only — CLAP and built-in effects, sends, and automation are not included in the exported file, only the built-in synths, samples, and step/note sequencing.

Automation

Every Region can carry its own automation lanes, edited in an "Automation" panel below the Piano Roll/Beats grid for whichever Region is currently open (see Tracks & Playlist). A lane rides one of:

  • the track's Volume or Pan,
  • one of the track's own send levels,
  • or a parameter of an effect loaded in the track's own FX chain — built-in effects expose their sliders' own parameters by name; a CLAP plugin's parameters are only offered once it's actually loaded into that slot.

Use + Add Lane to pick a target, then click empty space on the lane's graph to add a point, drag a point to move it (both time and value), or right-click a point to delete it — a straight line between two points is a ramp; more points make a full "ride." Automation is scoped to that one Region: it can't target another track, a send's own chain, or the master bus, and its points are positioned relative to the Region's own start rather than an absolute song position.
