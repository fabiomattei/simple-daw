Technical Overview

simple-daw

A native Rust MIDI sequencer / groovebox for composing video game music — deliberately not a general-purpose DAW.

Its scope is narrow and on purpose: a step sequencer, a piano roll, three built-in synth engines, sample playback and non-destructive audio-clip editing, a Logic/Ableton-style Playlist timeline, WAV bounce, MIDI import, JSON song persistence, CLAP effect hosting, and a set of composition tools (quantize/humanize/groove, tempo mapping). This documentation is split into two tracks depending on what you're trying to do.

User Manual

Learn to use the app, start to finish — installing it, building your first track, every window and editing surface, and a handful of full case studies. Start here if you want to make music with it.

Technical Documentation

The data model and engine architecture — how a song is represented, how it's played back in real time, and how the pieces fit together. Start here if you're reading or modifying the source.

Prerequisites

  • A Rust toolchain, installed via rustup.
  • On Linux: ALSA development headers for cpal's audio backend (alsa-lib-devel on Fedora, libasound2-dev on Debian/Ubuntu).

Build & run

cargo build       # debug build
cargo run         # launch the GUI app
