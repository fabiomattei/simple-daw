simple-daw

A native Rust MIDI sequencer / groovebox for composing video game music — deliberately not a general-purpose DAW.

Its scope is narrow and on purpose: a step sequencer, a piano roll, three built-in synth engines, sample playback, a Logic/Ableton-style Playlist timeline, WAV bounce, MIDI import, JSON song persistence, and CLAP effect hosting. This site walks through how to use each part of the app.

Prerequisites

  • A Rust toolchain, installed via rustup.
  • On Linux: ALSA development headers for cpal's audio backend (alsa-lib-devel on Fedora, libasound2-dev on Debian/Ubuntu).
  • Optional: a .clap plugin on disk if you want to try CLAP effect hosting — none ship with the repo. See Effects.

Build & run

cargo build       # debug build
cargo run         # launch the GUI app

Tests

cargo test              # unit tests: audio DSP math, model editing logic, WAV export
cargo test <test_name>  # run a single test
Unit tests cover synth/DSP math and the WAV exporter, but can't prove the live audio path actually produces sound. There's no automated harness for that — audio-affecting changes should be verified by running the app and listening.

Project layout

For contributors: the crate is a flat set of top-level src/*.rs files, each one responsibility (data model, audio engine, UI, built-in effect DSP, CLAP hosting, sample loading, wavetables, MIDI import). See the repository's own CLAUDE.md for the full architecture notes.
